# ShadowWork FR

## Identite
- **Categorie** : Bien-etre / Self-help
- **Segment cible** : Francophones 20-40 ans en demarche de self-discovery (millennials/Gen Z urbains, lecteurs de Keila Shaheen/Carl Jung, communautes TikTok/Instagram #shadowwork)
- **Date de creation** : 2026-04-19
- **Statut** : Scoring
- **Marketplace cible prioritaire** : **App Store FR** (puis Play Store FR, puis francophonie CA-BE-CH)

## Probleme
- **Enonce** : Les francophones interesses par le shadow work n'ont aucune app native FR pour pratiquer — ils sont contraints d'utiliser des apps anglaises qu'ils ne comprennent qu'a moitie, ou des journaux papier non guides
- **Contexte d'usage** : Quotidien ou ritualise (soir, matin, pleine lune, stress emotionnel). L'utilisateur veut explorer des parts inconscientes, patterns familiaux, blessures d'enfance, sabotages relationnels — via prompts guides et journaling structure.
- **Alternative actuelle** : Apps anglaises (Prompted Journal 474K installs, Zenfulnote 68K, Mindberg 65K), livres FR (Keila Shaheen/Albin Michel, Isaline Gayraud/Hachette), PDF gratuits, Notion templates, posts TikTok
- **Pourquoi c'est penible** :
  - Apps leaders = **100% anglais in-app** (reviews 1★ explicites : "Uniquement en Anglais")
  - Livres FR = pas d'interaction, pas de suivi, pas de rappel, pas de rituel
  - PDF/Notion = bricolage, pas d'experience produit
  - Prompted Journal = crashes + perte de donnees (pas de cloud sync)
  - Zenfulnote = book-to-app double-dip ressenti comme arnaque
  - Mindberg = paywall agressif + AI slop

## Audit Sonnet 2026-04-19 (score 89 → 70)

### Corrections appliquees

1. **Trend STABLE (1.00) pas UP (1.08)** : l'index FR actuel = 0 et la moyenne 12 mois = 20/100 sur micro-volume. Le +692% est un artefact mathematique, pas un signal terrain exploitable. Appliquer UP etait une erreur d'interpretation. La cible est francophonie, le multiplicateur doit refleter le marche cible.

2. **Flag market_education -10** : "shadow work" reste un terme anglais que les francophones ne tapent pas dans l'App Store FR. Index FR 0 = pas de comportement de recherche etabli. Meme logique qu'applique a DecidR. TikTok fait de l'awareness, pas du comportement d'achat App Store.

3. **personal_fit 4 → 3** : l'asset "site FR existant" est une hypothese, pas une donnee. Aucune info sur trafic, keywords, mailing list, demographie ou topic. Violation de la regle "donnees avant hypotheses".

4. **Conversion 1.5% (market_education)** : la conversion 2.5% initiale etait un choix arbitraire entre 1.5% (market_education) et 3% (marche etabli). Coherence avec le flag applique.

5. **Pricing 4.99€/mois ou 49€/an** (au lieu de 39€/an) : 18% discount standard premium, coherent avec argument ARPU iOS. 39€/an etait 35% discount = price-sensitive, contradictoire.

6. **Forecast realigne sur SOM Solo Dev Y1** : l'ancien forecast M12 = 27K€/mois etait fantasme (impliquait capture 53% du TAM payants solo dev sans budget). Realigne sur ~1.4K€/mois base.

### Ce qui est maintenu
- Territoire FR objectivement vierge (reviews 1★ explicites)
- Livres FR (Shaheen/Gayraud) prouvent demande latente
- Concurrence mediocre en qualite (3.55-4.37 etoiles)
